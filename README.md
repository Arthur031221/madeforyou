# madeforyou

The link-in-bio page for the Instagram account [@madeforyou.tools](https://www.instagram.com/madeforyou.tools/): every free tool in one place, in Traditional Chinese first and English second.

Live page: https://arthur031221.github.io/madeforyou/

Each tool runs in the browser and needs no account:

| Tool | What it does |
|---|---|
| [Sunspill](https://github.com/Arthur031221/Sunspill) | Where sunlight lands in your room, hour by hour |
| [Rumbleback](https://github.com/Arthur031221/Rumbleback) | Replay a real earthquake and see when its waves reach you |
| [OohAlive](https://github.com/Arthur031221/OohAlive) | Make parts of a photo flow and save a GIF |
| [ChitWeave](https://github.com/Arthur031221/ChitWeave) | Weave a LINE chat export into a picture |
| [Jostle](https://github.com/Arthur031221/Jostle) | Drag one task and the rest of the day makes room |
| [WishYouWereHere](https://github.com/Arthur031221/WishYouWereHere) | A stamp sheet of places that friends open one by one |
| [Beholden](https://github.com/Arthur031221/Beholden) | Shape a repository's stars into a thank-you sky |
| [Dollopify](https://github.com/Arthur031221/dollopify) | Split a restaurant bill by what each person ate |

The page is a single static `index.html` with no build step. Open it locally to preview.
